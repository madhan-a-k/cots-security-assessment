# cots-security-assessment
Reviews COTS hardware and firmware security for SoCs, MCUs, FPGAs, ASICs, NICs, TPMs, storage and PCIe/USB devices. Uses datasheets, manuals, security guides and errata to perform threat modeling, CVSS scoring, register/fuse/lock audits, access-control reviews and security triage, producing self-contained HTML security and threat-model reports now
